# Texto Base para o Relatório Final

## Implementação do Sistema

A etapa de implementação consistiu na criação de uma aplicação web voltada à gestão e rastreabilidade de tarefas dos adultos voluntários do 453º Grupo Escoteiro Alpha Centauri. O sistema foi estruturado com uma separação entre frontend, backend e banco de dados, permitindo maior organização e facilidade de manutenção.

O backend foi desenvolvido com Node.js e Express, responsável por disponibilizar rotas para consulta, cadastro e atualização de tarefas. O frontend foi desenvolvido com React, priorizando uma interface simples e objetiva para visualização dos dados. O banco de dados relacional foi modelado para contemplar seções, adultos voluntários, tarefas, dependências entre tarefas e histórico de alterações de status.

## Rastreabilidade

A rastreabilidade é garantida por meio do registro de responsáveis, prazos, status e histórico de alterações. Dessa forma, a Diretoria de Métodos Educativos pode acompanhar a evolução das tarefas e identificar pendências, atrasos e impedimentos.

## Controle de Versão

O projeto utiliza Git e GitHub para registrar a evolução incremental do desenvolvimento. Os commits foram organizados conforme boas práticas, utilizando mensagens padronizadas como `feat`, `fix` e `docs`.

## Resultado

Como resultado, obteve-se um protótipo funcional capaz de demonstrar o cadastro, listagem e acompanhamento de tarefas, contribuindo para a organização administrativa do grupo escoteiro.
